# DentalClinic-Microservices

A microservices-based dental clinic management system built with .NET 9, using Domain-Driven Design.

## Services / components
AuthService (authentication/authorization), BookingService (DDD), PaymentService (DDD), GatewayService (YARP API Gateway + JWT), OrchestratorService (workflow orchestration), Umbraco CMS integration, .NET Aspire AppHost (orchestration and monitoring).

## Technologies
.NET 9, C#, ASP.NET Core, DDD, YARP API Gateway, JWT authentication, Dapr, Dapr Workflow, .NET Aspire, Umbraco CMS, Docker, SQLite (per-service databases), Entity Framework Core.

## Engineering topics demonstrated
Authentication/authorization, API Gateway pattern, distributed systems, service boundaries, workflow orchestration, configuration security, testing and error handling, distributed application monitoring (.NET Aspire dashboard).

## Evidence level
Tier 1 project for: DDD, Microservices, distributed architecture, API Gateway, Dapr, .NET Aspire, JWT.
