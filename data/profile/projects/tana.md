# TANA — Travel Management System

Professional travel booking and itinerary management platform.

## Architecture
ASP.NET Core 8, Clean Architecture, CQRS Pattern — TANA.API (REST + Swagger), TANA.Web (Blazor Server), TANA.Domain, TANA.Application (CQRS), TANA.Infrastructure, TANA.Persistence (EF Core).

## Features
Tours, customers, bookings, custom itineraries, PDF travel documents (QuestPDF), English/Danish localization, session-based authentication/authorization, customizable templates, responsive Blazor Server + Bootstrap UI.

## Technologies
ASP.NET Core 8, Blazor Server, Bootstrap, Entity Framework Core, SQL Server/LocalDB, Docker, QuestPDF, JavaScript.

## Evidence level
Tier 2 — supporting evidence for Clean Architecture, CQRS, multi-language support, PDF generation, session auth.
