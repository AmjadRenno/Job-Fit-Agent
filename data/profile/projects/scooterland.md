# ScooterLand — Workshop Management System

Workshop management system developed during the second semester at UCL, for scooter repair and maintenance services.

## Technologies
Blazor WebAssembly + Radzen Components (frontend), ASP.NET Core 8.0 Web API (backend), SQL Server + Entity Framework Core (database), Bootstrap (UI).

## Features
Customer management, work orders/repair orders, invoice generation, mechanic management and specializations, service catalog with pricing/time estimates, brand management.

## Evidence level
Tier 3 — academic/training-level evidence (second-semester coursework).
