# EDC — Real Estate Management System

Internal real estate management application, developed as a first-semester university coursework project.

## Technologies
.NET 8, Windows Forms, Clean Architecture with MVP pattern, JSON local persistence, Async/Await.

## Features
Realtor management, customer management, property management with advanced filtering, validation, modern (Material Design-inspired) UI, Danish localization.

## Engineering practices
SOLID principles, separation of concerns, error handling, async programming, reusable UI components.

## Evidence level
Tier 3 — academic/training-level evidence (first-semester coursework), useful for demonstrating early SOLID/Clean Architecture application, not a professional-context project.
