# Umbraco Fundamentals Training Project

Training project created as part of the Umbraco Fundamentals Team Training course, to practice core Umbraco CMS development concepts.

## Technologies
ASP.NET Core 9.0, Umbraco CMS 16.1.1, SQLite (development), HTML/CSS/JavaScript, Razor Views.

## Concepts practiced
Document Types, Data Types, Templates, Razor Views, Partial Views, content structures, media management, Block Grid, Block List, content modelling, multilingual content concepts.

## Related certification
Umbraco Professional — issued August 2025, valid through August 2027.

## Evidence level
Tier 3 — training-project-level evidence, directly tied to a real certification.
