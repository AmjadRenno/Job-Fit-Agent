# SupplyBase (DanskMarked) — B2B Commerce Portal

Customizable B2B industrial commerce portal. Private repository.

## Architecture
ASP.NET Core 10, Razor Pages, Clean Architecture.

## Features
Company accounts (organizations, members, roles, approval workflows, shared order history), customer groups with tiered pricing, quote-request workflow, catalog management, product technical data, reordering, order administration, admin dashboard, inline content editing, audit logging, Stripe payments with webhook-driven order updates, Shipmondo shipping integration, background jobs.

## Evidence level
Tier 2 — supporting evidence for B2B domain modelling, role/organization management, payment integration, webhooks, background processing, auditability, Clean Architecture.
