# Personal Portfolio Website

Personal portfolio built with Next.js 16, TypeScript, and Tailwind CSS to present professional focus and projects.

## Technologies
Next.js 16 (App Router), TypeScript, Tailwind CSS, Resend (email), Vercel (deployment).

## Features
Bilingual (Danish default + English), centralized content management, responsive UI, project showcase with GitHub links, real working contact form via Resend, Next.js API route for email sending.

## Evidence level
Tier 2 — supporting evidence for frontend/full-stack Next.js development and deployment, separate from the C#/.NET-focused evidence base.
